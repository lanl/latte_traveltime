* To generate training data, you need to install [RGM](https://github.com/lanl/rgm) first, and `make` and run the compiled executables. `generate_data_2d.f90` and `generate_data_3d.f90` (`exec2` and `exec3`) are the original generators; they use the RGM types `rgm2` and `rgm3`, which RGM 2.0 keeps for backward compatibility. `generate_data_2d_v2.f90` and `generate_data_3d_v2.f90` (`exec2_v2` and `exec3_v2`) use the RGM 2.0 types `rgm2_curved` and `rgm3_curved` with fixed random seeds, so every run generates the same data. 
* The script `train.sh` will train the NNs, but depending on your machine's configuration, you may need to adjust the number of nodes, number of GPUs, and batch size accordingly.
